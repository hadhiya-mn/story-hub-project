# 🌍 StoryHub - Django Blogging Platform

StoryHub is a modern Django-based blogging platform where users can create, explore, like, comment, and save blogs through a clean and responsive web interface.

The project includes user authentication, profile management, blog interactions, and an admin dashboard for managing users and blog posts.

---

## 🚀 Features

* 🔐 User Registration & Login Authentication
* 📝 Create, Edit & Delete Blogs
* 🌍 Explore Blogs Feed
* ❤️ Like & Comment System
* 🔖 Save Blogs Feature
* 👤 User Profile Management
* 📷 Profile Picture Upload
* 🔍 Search Blogs Functionality
* 🛡️ Admin Dashboard
* 👥 Admin Can View All Users
* 📚 Admin Can Manage All Blogs
* 🎨 Modern Responsive UI
* 🌐 Live Deployment using Render

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/hadhiya-mn/story-hub-project.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd story-hub-project
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
python manage.py runserver
```

Open in browser:

```text
http://127.0.0.1:8000/
```
